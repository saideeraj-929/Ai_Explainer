# 🤖 AI Code Explainer

An AI-powered desktop application built with **Python**, **Tkinter**, and the **Groq API** that explains Python code in simple, beginner-friendly English.

---

## 📌 Features

* 📝 Paste Python code into the input box.
* 🤖 AI explains the code line by line.
* 📖 Beginner-friendly explanations.
* 💾 Save explanations to a text file.
* 📂 Load previously saved explanations.
* 🧹 Clear both the input and output fields.
* ⚠️ Error handling for invalid input or API issues.

---

## 🛠️ Technologies Used

* Python 3
* Tkinter

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AI-Code-Explainer.git
```

2. Install the required package:

```bash
pip install groq
```

3. Set your Groq API key as an environment variable.

4. Run the application:

```bash
python main.py
```

---

## 🖥️ How to Use

1. Open the application.
2. Paste Python code into the input box.
3. Click **Explain Code**.
4. Read the AI-generated explanation.
5. Save or load explanations using the provided buttons.
